# Бухоро вилояти: Амударё суви — тақсимот — даромад — самарадорлик

Амударёдан Аму-Бухоро машина канали (АБМК) орқали Бухоро вилоятига олинадиган
сувнинг туманлар кесимида тақсимланиши, шу сув ҳисобига олинаётган қишлоқ
хўжалиги даромади ва сувдан фойдаланиш самарадорлигининг эконометрик таҳлили.

**Панель:** 11 туман × 2014–2024 йиллар = **121 кузатув**

---

## ⚠️ Маълумотлар манбаи ҳақида муҳим огоҳлантириш

Бу лойиҳадаги рақамлар **индикатив (баҳоланган)** бўлиб, қуйидагича
шакллантирилган:

1. **Йиғма кўрсаткичлар** (вилоят бўйича жами сув олиш ≈ 3.5–4.1 км³/йил,
   суғориладиган майдон ≈ 274 минг га, ялпи ўсимликчилик маҳсулоти) АБМК
   тизими ва вилоят статистикасининг эълон қилинган даражасига **лангарланган**.
2. **Туманлар кесимидаги тақсимот** агрономик норматив (м³/га), тупроқ
   шўрланиши ва каналдаги жойлашув (бош/ўрта/охирги оқим) омиллари асосида
   **калибрланган**.
3. **Ялпи маҳсулот** Кобб-Дуглас ишлаб чиқариш функцияси генератори орқали
   ҳосил қилинган — шу боис эконометрик боғланишлар ички жиҳатдан изчил.

**Расмий рақамларингиз бўлса**, `data/buxoro_suv_panel.csv` файлини устун
номларини сақлаган ҳолда алмаштиринг ва `02` ҳамда `03` скриптларини қайта
ишга туширинг — бошқа ҳеч нарсани ўзгартириш шарт эмас. Барча жадвал, тест ва
график автоматик янгиланади (субтитрлардаги статистик кўрсаткичлар ҳам
`kalit_korsatkichlar.json` орқали динамик равишда олинади).

## Асосий натижалар (2024 йил)

### Сув баланси: Амударёдан далагача

| Босқич | млн м³ | Улуш |
|---|---:|---:|
| Амударёдан олинган (АБМК бош иншооти) | 4 027 | 100.0% |
| Магистрал каналда йўқотилган | −515 | 12.8% |
| Туманларга етказилган | 3 512 | 87.2% |
| Хўжаликлараро ва ички тармоқда йўқотилган | −1 170 | 29.1% |
| **Далага реал етган** | **2 342** | **58.1%** |

Тизимнинг умумий ФИК = **0.581**. Яъни Амударёдан олинган ҳар 100 м³ сувнинг
атиги 58 м³ и экин илдизига етиб боради. 2014→2024 да ФИК 0.470 → 0.581 га
ошган (+11.1 фоиз пункт).

### Тақсимот ва самарадорлик

- Ўртача солиштирма сарф: **12 826 м³/га**
- Вилоят бўйича сув унумдорлиги: **4 283 сўм/м³** (0.335 USD/м³)
- Туманлар ўртасидаги фарқ: **1.83 марта** (Олот 2 897 → Шофиркон 5 302 сўм/м³),
  вариация коэффициенти 15.8%
- Канал зонаси бўйича фарқ статистик жиҳатдан аҳамиятли:
  ANOVA F = 7.36, p = 0.015
- Джини: сув таъминоти 0.052 (нисбатан текис) ↔ сув унумдорлиги 0.091
  (анча нотекис) — **самарадорлик захираси айнан шу фарқда**

### Эконометрик баҳолар

Кобб-Дуглас ишлаб чиқариш функцияси, панель FE (туман + йил эффектлари),
кластер-мустаҳкам стандарт хатолар:

| Омил | Эластиклик | Ст. хато | p |
|---|---:|---:|---:|
| Сув | **0.237** | 0.049 | < 0.001 |
| Меҳнат | 0.173 | 0.066 | 0.010 |
| Капитал | 0.136 | 0.066 | 0.043 |
| Ер (CRS шарти остида қолдиқ) | 0.453 | — | — |
| Шўрланиш индекси | −0.498 | 0.205 | 0.017 |

**Талқин:** сув сарфи 10% га камайса, ялпи маҳсулот тахминан **2.4%** га
камаяди. Сув эластиклиги адабиётдаги 0.1–0.4 диапазонига мос келади.

- **Сувнинг чекли маҳсулдорлиги (MPW)** = 1 016 сўм/м³ (0.080 USD/м³) — бу
  сувнинг иқтисодий соя нархи. Амалдаги сув тарифи шундан анча паст бўлса,
  сувни тежашга иқтисодий рағбат вужудга келмайди.
- **Техник самарадорлик:** DEA (CRS) ўртача 0.923, SFA ўртача 0.935. Икки
  усулнинг рейтинглари мос: Спирмен ρ = 0.71 (p = 0.015).
- **Сув ҳисоблагичлари билан қамров** самарадорликка мусбат ва статистик
  аҳамиятли таъсир кўрсатади (p = 0.009).

### Сув тежаш салоҳияти

- Илғор чорак (25-перцентиль = 11 871 м³/га) даражасига етилса,
  **287 млн м³/йил** (жами сувнинг 8.2%) тежалади.
- DEA бўйича назарий тежаш салоҳияти: **272 млн м³/йил** (7.7%).

## Ишга тушириш

### Python (бу ерда ҳисоб-китоб бажарилган)

```bash
python scripts/01_malumot_yaratish.py && python scripts/02_tahlil.py && python scripts/03_grafiklar.py
```

Керакли пакетлар:

```bash
pip install pandas numpy statsmodels linearmodels scipy matplotlib openpyxl
```

### Stata

`stata/buxoro_suv_tahlil.do` файлида `global yol` ни ўз папкангизга
мослаштиринг, сўнг Stata да:

```bash
do "stata/buxoro_suv_tahlil.do"
```

Қўшимча пакетлар (интернет талаб қилинади):

```bash
ssc install estout dea heatplot palettes colrspace fastgini, replace
```

**Эслатма:** SSC даги `dea` пакетининг синтаксиси версияга қараб фарқ қилади —
ишга туширишдан аввал `help dea` орқали текширинг. Агар ишламаса, do-файлдаги
«МУҚОБИЛ ЙЎЛ» блокини изоҳдан чиқариб, Python да ҳисобланган DEA балларини
улаш мумкин. Кирилл матн учун Stata 14 ёки юқори версия керак.

## Методология

| Блок | Усул | Мақсад |
|---|---|---|
| A | Сув баланси, ФИК декомпозицияси | Йўқотишларни босқичма-босқич ажратиш |
| B | Улушлар таҳлили | Тақсимот майдон улушига мослигини текшириш |
| C | Сув унумдорлиги, сув сиғими, ANOVA | Самарадорлик индикаторлари ва зона фарқи |
| D | Джини коэффициенти, Лоренц эгри чизиғи | Тақсимот тенгсизлигини ўлчаш |
| E | Кобб-Дуглас: Pooled OLS / FE / RE, Хаусман, VIF | Ресурс эластикликларини баҳолаш |
| F | MPW = b × (Y/W) | Сувнинг иқтисодий соя нархи |
| G | DEA (CRS/VRS), чизиқли дастурлаш | Чегарага нисбатан техник самарадорлик |
| H | SFA (half-normal MLE, Jondrow ва б.) + 2-босқич | Самарасизликни шокдан ажратиш |
| I | Бенчмаркинг + эластиклик сценарийлари | Тежаш салоҳияти ва сиёсат вариантлари |

### Эконометрик спецификация ҳақида

Экстенсив шакл (`ln Y = f(ln сув, ln меҳнат, ln ер, ln капитал)`) да
суғориладиган майдон панелда деярли ўзгармас бўлгани учун ер ва сув
коэффициентлари ўзаро коллинеар бўлиб қолади. Шу боис **базавий баҳо сифатида
интенсив (1 га га келтирилган) шакл** олинган — бу доимий миқёс самараси
шартини юклайди ва аграр иқтисодиётда стандарт усул ҳисобланади. Иккала шакл
ҳам ҳисоботда келтирилган ва сув эластиклиги бўйича амалда бир хил натижа
беради (0.238 ва 0.237).

### Графиклар дизайни

Валидациядан ўтган палитра ишлатилган: миқдор — кетма-кет кўк рамп,
қутбийлик — дивергент кўк↔қизил, идентиклик — категориал 1–3 слот.
Икки ўқли (dual-axis) графиклар ишлатилмаган — турли ўлчовдаги кўрсаткичлар
2014 = 100 индексига келтирилган. Барча графикда қиймат ёрлиқлари бевосита
кўрсатилган.
